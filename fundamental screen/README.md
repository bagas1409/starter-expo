# Panduan Lengkap Navigasi Screen & Tab Bar di Expo Router

Selamat datang di modul **Fundamental Screen & Navigasi**! Panduan ini dirancang untuk mengajarkan bagaimana cara mengelola halaman aplikasi, membedakan screen tab bar dan screen mandiri, serta mengatur perpindahan antar layar menggunakan tombol di Expo React Native.

---

### 📚 Daftar Panduan Pembelajaran:

1. [Modul 01: Konsep Dasar File-Based Routing](file:///c:/Users/bagas/Desktop/belajar/Aplikasi/fundamental%20screen/01-konsep-expo-router.md)  
   👉 Memahami bagaimana struktur folder `app/` otomatis menjadi rute halaman di Expo.

2. [Modul 02: Membuat Screen Baru yang Masuk ke Tab Bar](file:///c:/Users/bagas/Desktop/belajar/Aplikasi/fundamental%20screen/02-membuat-screen-tabbar.md)  
   👉 Langkah membuat file di `app/(tabs)/` dan mendaftarkan ikonnya di `app/(tabs)/_layout.tsx`.

3. [Modul 03: Membuat Screen Baru yang BUKAN di Tab Bar (Full Screen / Stack)](file:///c:/Users/bagas/Desktop/belajar/Aplikasi/fundamental%20screen/03-membuat-screen-bukan-tabbar.md)  
   👉 Membuat halaman mandiri (layar penuh menutup menu bawah) langsung di dalam folder `app/`.

4. [Modul 04: Cara Berpindah Screen Menggunakan Tombol](file:///c:/Users/bagas/Desktop/belajar/Aplikasi/fundamental%20screen/04-navigasi-tombol-router.md)  
   👉 Menggunakan `router.push()`, `router.replace()`, `router.back()`, dan komponen `<Link>`.

5. [Modul 05: Cara Mengirim & Menerima Data Antar Screen](file:///c:/Users/bagas/Desktop/belajar/Aplikasi/fundamental%20screen/05-mengirim-data-antar-screen.md)  
   👉 Mengoper data dinamis dengan `params` dan membongkarnya dengan `useLocalSearchParams()`.
